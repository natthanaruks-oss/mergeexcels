# Office Toolkit v4.3.0 — Phase 1C Image to PDF

## Added
- New Image to PDF module for JPG, PNG and WebP.
- Multi-image ordering via existing file-order controls and drag/drop.
- A4 Fit or Original Size pages.
- Auto / Portrait / Landscape orientation for A4 pages.
- 0–20 mm margin presets.
- High / Balanced / Small-file image quality presets.
- Local image preview before export.

## Safety
- Input images are never modified.
- Conversion remains browser-local.
- No OCR/searchable text is claimed for the generated PDF.

## Status
Build/regression verification required before deployed UAT.
