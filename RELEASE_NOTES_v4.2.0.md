# Office Toolkit v4.2.0 — Phase 1B PDF Watermark & Stamp

## Added
- Menu 13 PDF Watermark & Stamp
- DRAFT / CONFIDENTIAL / INTERNAL USE / Custom text
- 9 positions, opacity, font size and rotation
- All / First / Last / custom page range
- Optional Page X of Y and source filename footer
- Thumbnail position preview

## Safety
- Input PDF is never overwritten.
- Local-only processing.
- Existing digital signatures may become invalid after PDF modification.
- Custom stamp text currently supports Latin/English via the built-in PDF standard font. Thai glyphs are rejected rather than silently corrupted.

## Status
Build and automated regression verification required before release packaging. Deployment/UAT must be verified separately in Codespaces.
